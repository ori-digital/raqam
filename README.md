# Рақам — сайт продукта

Публичный лендинг платформы **Рақам**: чек-листы смен с фотоотчётом, приход и уход
с геозоной, обучение и аттестация, расчёт премий, дашборд руководителя — в одном
приложении в Telegram, под брендом клиента.

Опубликован через GitHub Pages: **https://ori-digital.github.io/raqam/**

## Что здесь

| Файл | Назначение |
|---|---|
| `index.html` | вся страница: разметка, стили и скрипт в одном файле, без сборки |
| `.preview-server.ps1` | локальный статический сервер для проверки (порт 8199) |

Внешних запросов страница не делает — ни шрифтов, ни CDN, ни аналитики. Это осознанно:
лендинг должен открываться быстро и на медленном мобильном интернете.

## Локальная проверка

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\.preview-server.ps1
```

Затем открыть http://localhost:8199/ — сервер отдаёт `index.html` по корню.
Тот же сервер заведён в `.claude/launch.json` под именем `raqam-landing`.

## Перед публикацией заполнить

В конце `index.html`, в блоке `<script>`:

```javascript
var FORM_ENDPOINT = '';   // URL веб-приложения Apps Script (.../exec)
var TELEGRAM = '';        // https://t.me/<аккаунт> — запасной канал связи
```

Пока `FORM_ENDPOINT` пуст, форма заявки не отправляет данные, а честно сообщает об этом
и предлагает написать в Telegram. Код приёмника заявок (пишет в Google-таблицу
и опционально шлёт уведомление в Telegram) лежит в основном репозитории платформы:
`Raqam/docs/landing-form-receiver.gs`.

Секреты (`BOT_TOKEN`, адрес развёртывания) в репозиторий не попадают — `FORM_ENDPOINT`
это публичный URL веб-приложения, он безопасен, но токен бота держится на стороне
Apps Script.

## Связь с основным репозиторием

Код самой платформы (шелл, ядро, сервер) живёт в приватном репозитории `Raqam`.
Здесь только витрина: приватный репозиторий не может отдавать GitHub Pages
на бесплатном тарифе, поэтому сайт вынесен отдельно.

Цены на странице должны совпадать с `Raqam/docs/Прайс платформы Рақам (ред. N).docx` —
при пересмотре тарифов правятся оба места.
